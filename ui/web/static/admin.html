CodeAgent Admin

Groups define tools and OpenRouter model ids (API model field, e.g. minimax/minimax-m2.5:free). Users inherit the union of groups; first model id is used for chat. Use * for all tools or all models (then names come from config.yaml). Needs OpenRouter base URL + API key in config. At least one user must stay in the admin group.
